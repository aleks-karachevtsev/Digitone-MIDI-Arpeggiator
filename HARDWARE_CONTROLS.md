# Hardware controls

1. Select MIDI track A, B, C or D and set its desired MIDI output channel.
2. Use **FUNC + ADD NOTES/ARP** (the musical-note button above PTN) to toggle MIDI ARP. Its yellow indicator reflects the enabled state of the selected MIDI track. The MODE value is retained when toggled off.
3. Use **FUNC + SYN1** to open the existing ARP page. The normal encoders edit MODE, SPEED, RANGE and LEN; the graphical editor edits enabled steps and pitch offsets. Encoder F in the graphical editor changes active pattern length (1–16 steps). A disabled step is a timed rest.
4. Play the Digitone keys or recorded MIDI trigs. Connect MIDI DIN OUT to the external synth's MIDI IN and match the channel.

Normal SPEED turning remains the stock fine adjustment. Press-and-turn musical division navigation is **not present** in DA27. It is being investigated because the stock handler accelerates the turn before the current ARP setter sees it. LATCH is not implemented. On synth tracks T1–T4, the stock ARP controls remain in effect.
